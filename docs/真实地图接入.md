# 真实地图接入说明

本版用 [Leaflet](https://leafletjs.com/examples/quick-start/) 加载 [OpenStreetMap 标准地图瓦片](https://operations.osmfoundation.org/policies/tiles/)，在总览和调度页显示西南交通大学犀浦校区周边的真实街道。浏览器需联网；公开瓦片服务不保证持续可用，正式部署应按使用量选择有服务保障的地图提供商。页面持续显示 OpenStreetMap 版权署名，不预取、批量下载或离线打包瓦片。

地图视野以 [犀浦校区](https://www.openstreetmap.org/way/207566638) 为中心参考。两个轨道接驳示范标记分别使用 [兴业北街站](https://www.openstreetmap.org/node/8242501078) 和 [犀浦站](https://www.openstreetmap.org/node/7951474426) 的公开坐标作为定位参考。其余标记仅为校区周边演示布局，均未经实地停车区测绘；车站坐标也不等于实际单车停车位置。

这次仅将区域标记接入地理底图。页面上的调度虚线是起终点直线示意，后端任务距离仍按原来的模拟网格估算，并非道路行驶距离或导航路线。毕业设计若要评价真实调度效果，应先现场确认停车边界、车辆库存和可达道路，再接入合适的路线服务并替换距离模型。
