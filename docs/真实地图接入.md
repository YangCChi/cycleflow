# 真实地图接入说明

本版默认用 [高德 JS API 2.0](https://lbs.amap.com/api/javascript-api-v2/summary) 加载真实街道底图；未配置 Key、Key 失效或加载失败时，回退到 [Leaflet](https://leafletjs.com/examples/quick-start/) + [OpenStreetMap 瓦片](https://operations.osmfoundation.org/policies/tiles/)（优先 OSM Germany，再回退 Esri World Street Map）。Key 与安全密钥放在 `frontend/.env.local`，不进入 Git。高德使用 GCJ-02 坐标，页面会把公开的 WGS-84 坐标转换后再标注。浏览器需联网；公开瓦片服务不保证持续可用，正式部署应按使用量选择有服务保障的地图提供商。页面保留高德或 OpenStreetMap 版权署名，不预取、批量下载或离线打包瓦片。

地图视野以 [犀浦校区](https://www.openstreetmap.org/way/207566638) 为中心参考。两个轨道接驳示范标记分别使用 [兴业北街站](https://www.openstreetmap.org/node/8242501078) 和 [犀浦站](https://www.openstreetmap.org/node/7951474426) 的公开坐标作为定位参考。其余标记仅为校区周边演示布局，均未经实地停车区测绘；车站坐标也不等于实际单车停车位置。

调度页的路线几何由高德 JS API 的 `AMap.Driving` 插件沿道路绘制。任务里程、运输时长和仿真实验的距离统一读取高德 Web 服务距离测量接口生成的 12×12 区域道路矩阵：接口使用驾车模式（`type=1`，会考虑实时路况），结果缓存在 `road_matrix` 表中，并使用根目录 `.env` 中的 `AMAP_WEB_KEY` 刷新。矩阵未就绪、Key 未配置或接口失败时，回退为起终点直线和模拟网格估算。由于路况和缓存时间会影响结果，矩阵不是固定不变的道路数据；路线几何与矩阵时长也可能因策略或路况略有差异。毕业设计若要评价真实调度效果，还应现场确认停车边界、车辆库存和可达道路。
