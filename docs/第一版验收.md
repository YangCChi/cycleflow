## 库存与任务验收规则

- 生成任务仅预留数量，不立即扣减停车区域库存。
- 开始执行时源点减车，单车计入运输中；到达时目的点加车。测试检查全程车辆总量保持 500。
- 每辆运输车同一时刻最多承担一项待执行或运输中的任务。
- 容量不能小于现有车辆加已安排调入量；库存和容量不会出现负数或超限。
- 只能取消待执行任务，取消后释放预留；任务不能重复开始。
- 三种实验策略共享同一批请求；一次失败借车不生成对应还车；结束时在途车辆计入总数。
