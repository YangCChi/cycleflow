# 交点 CycleFlow

西南交通大学犀浦校区周边共享单车智能调度系统，毕业设计第一版原型。

**Spring Boot 4.1.1 / Java 21 + Vue 3 / Vite + H2 本地文件数据库。**

## 启动

环境：Java 21+、Maven 3.9+、Node.js 22.12+（或支持当前 Vite 的更新版本）。首次运行需要联网安装公开依赖。

```bash
./scripts/start.sh
```

打开 <http://127.0.0.1:8080>。Spring Boot 同时提供前端页面与 API，不需要单独安装数据库。服务默认只监听本机。已有程序占用端口时，可使用 `PORT=8081 ./scripts/start.sh`。

启动脚本使用项目内 `.m2/` 和 `.npm-cache/` 缓存依赖，均不进入 Git。构建后的可执行文件是 `backend/target/cycle-dispatch-0.1.0.jar`。

开发前端：先启动后端，再在 `frontend` 目录运行 `npm run dev`，访问 <http://127.0.0.1:5173>；开发代理默认后端端口为 8080。

## 已实现

- 运营总览：OpenStreetMap 真实街道底图、12 个示范区域、500 辆单车、缺口排序、选中区域查看详情。
- 停车区域：搜索、类型筛选、修改名称、停车容量及安全库存，保存至后端。
- 需求预测：按场景规则计算未来借还量、两小时曲线和分时段供需余额。
- 智能调度：缺口优先、就近匹配、每车载量 20 辆、两辆运输车；生成、取消、执行任务。
- 搬运播放：每步推进 5 分钟；取车后计为运输中，到达后增加目的地库存。
- 仿真实验：不调度、阈值就近、预测优先三种策略；同种子生成相同的 1,260 次请求，回放 180 分钟，结果可导出 CSV。
- 场景切换：工作日早高峰、晚高峰、周末；重置前说明清除范围。
- 响应式界面、键盘操作、加载／错误／空状态、数据与模型说明。

## 五分钟演示

1. 从运营总览查看总量和待补车区域，点击地图点位查看库存。
2. 进入停车区域，搜索“西门”，编辑安全库存并保存。
3. 打开需求预测，切换不同区域，查看预期借还趋势。
4. 生成调度方案，执行任务，点击“播放”或“+5 分钟”。观察源库存、在途库存、目的库存变化，以及总量始终为 500。
5. 完成或取消全部任务后，进入仿真实验，运行并导出 CSV。
6. 刷新验证状态保留；如需回到初始场景，使用“重置场景”。

## 数据与算法边界

这是可运行的工程原型，**不使用当地真实车辆、订单或 GPS 数据**。底图来自 OpenStreetMap，需要联网加载；12 个停车标记是候选地点／示范区域，未经现场核验。兴业北街站和犀浦站的公开坐标只作为接驳区域的定位参考，不代表站口旁已有合法停车位。容量、库存、需求与时间均为模拟参数。

地图支持缩放、拖动、选点和恢复视野。绿色虚线仅连接调度任务的起终点，不沿道路计算；任务里程仍由原有模拟网格估算，不能用于实际导航。地图服务及点位来源说明见 [docs/真实地图接入.md](docs/真实地图接入.md)。

需求预测目前为规则模型，没有训练机器学习模型。调度采用两点取送的贪心启发式，尚未接入 OR-Tools，不能称为全局最优。运输车假定在取车点就近待命，里程为取车点至送车点的网格估算，尚未计入运输车到取车点的空驶。

工作台时钟只推进搬运任务，不自动生成骑行订单；借还事件在独立仿真实验中发生。成功借车才生成还车；目的地暂满时车辆延后归还。实验结束时在途单车仍计入总量。实验基于当前地面库存，存在待执行或在途任务时禁止开始实验。

缺口会扣除已经安排的调入量；只有待执行任务能够取消；容量不能低于现有库存加已安排调入量。业务修改通过串行事务完成，以保证本地单用户原型的一致性。

## 数据存储

默认数据位置为 `backend/data/`（从启动脚本运行时）。刷新或重启保留区域和任务，重置演示会清除这些修改。此目录不进入 Git。请先停止程序再备份数据库文件。

本地演示使用 H2 的 MySQL 兼容模式。依赖已包含 MySQL 驱动，可通过 `DB_URL`、`DB_USER`、`DB_PASSWORD` 接入独立测试库；本版尚未验证 MySQL 实例，也未接入 MyBatis-Plus。不要在命令或源码里写入真实数据库密码。MySQL、MyBatis-Plus、道路路线服务和正式预测模型属于后续版本工作。

## 校验

```bash
./scripts/check.sh
```

自动化测试覆盖运输车重复分配、容量预留、重复执行、取送库存守恒、取消释放、区域校验、三种场景的实验可复现性及无效重置保护。手动验收记录见 [docs/第一版验收.md](docs/第一版验收.md)。

## 结构

```text
backend/    Spring Boot、事务、调度规则、仿真、测试
frontend/   Vue 页面、Leaflet 地图、图表、交互
scripts/    启动与校验脚本
docs/       规划与验收记录
```

API：`GET /api/state`、`PATCH /api/regions/{id}`、`GET /api/regions/{id}/forecast`、`POST /api/dispatch/generate`、`POST /api/dispatch/{id}/start`、`POST /api/dispatch/{id}/cancel`、`POST /api/simulation/advance`、`POST /api/simulation/reset`、`GET /api/experiments?seed=42`。
